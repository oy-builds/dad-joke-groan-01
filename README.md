# The One-Liner Groan-Off — Dad Joke

One original one-line dad joke (62 characters), written to
`/output/entry.txt` by `main.ts`:

> I told my mirror a joke — it cracked up, then reflected on it.

`main.ts` (Node 22, standard library only) validates the line — non-blank,
one line, at most 140 characters, valid UTF-8 — then writes it, so two
runs produce byte-identical output.
